# Pawan Chandiramani — Personal Website

A responsive personal portfolio built with React + Vite.

## Before publishing
1. Add your professional portrait at `public/images/profile.jpg`.
2. Replace `YOUR_EMAIL@example.com` in `src/main.jsx` with your public professional email.
3. Replace the LinkedIn placeholder URL with your actual profile.
4. Review every biography, experience and project description. Edit anything that does not accurately describe you.
5. Add verified project screenshots, demo links and APK download links only when ready.

## Run locally
Install Node.js (LTS), then in this folder run:

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal.

## Build for production
```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. Sign in to Vercel using GitHub.
3. Import the repository.
4. Keep the default Vite settings:
   - Framework preset: Vite
   - Build command: `npm run build`
   - Output directory: `dist`
5. Click Deploy.

Vercel should automatically rebuild the site whenever you push changes to the connected GitHub branch.

- No backend or database is required for this first version.
- Contact email and social links are placeholders until you replace them.
- The portrait area shows a styled placeholder until `public/images/profile.jpg` is added.
- This is a personal portfolio starter. Keep it non-commercial if using Vercel Hobby.
